Подключения

Один вход на площадку. После этого чат читается сам, а «Во все» уходит сразу в четыре чата.

К чату

Twitch

Redirect:

Кабинет: dev.twitch.tv → Applications. Категория Chat Bot. В Redirect URL вставь адрес выше.

YouTube

Redirect:

Google Cloud → включи YouTube Data API v3 → OAuth client, тип Web application, этот redirect. На длинном эфире дневная квота может кончиться: чат напишет об этом прямо в лампе YouTube.

Kick

Redirect:

Приложение создаётся в кабинете разработчика Kick. Чтение идёт тем же сокетом, что и сайт. Отправка — официальным API.

VK Видео

Redirect:

Приложение: dev.live.vkvideo.ru. Если кнопка входа не пускает, открой live.vkvideo.ru, F12 → Application → Local Storage → ключ auth → скопируй accessToken сюда.

Кого не показывать зрителям

Команды с «!» скрываются сами. В твоём окне они остаются, пометка «не на экране».

Как проверить и поставить в OBS

  1. Запусти start.bat на стримерском ПК и не закрывай чёрное окно. Игровой ПК для чата не нужен.
  2. В этом чате нажми «Проверить». Если видишь четыре площадки, а команды и Nightbot помечены «не на экране» — окно работает.
  3. Кликни ник зрителя, впиши как его звать на экране, «Сохранить ник». Пустое поле или «Как было» возвращает имя с площадки.
  4. Окно для тебя, его зрители не видят: OBS → Доки → Пользовательские доки браузера. Имя «Чат», адрес . Ширину дока можно тянуть.
  5. То, что видят зрители: в сцене «+» → Браузер. Адрес , ширина 480, высота 700. «Отключать источник, когда он не виден» сними. «Обновлять браузер при активации сцены» тоже лучше снять, иначе чат моргает при каждом переключении.
  6. Подвинь источник в угол. В студии OBS фон игры должен просвечивать между плашками. Если вместо этого серый квадрат, у источника Браузер в свойствах не должно быть своей заливки, а у страницы она уже прозрачная.
  7. Потом подключи аккаунты выше. Лампа площадки загорается своим цветом, когда чат читается. Напиши что-нибудь в чат площадки с другого аккаунта и ответь кнопкой «Во все».
